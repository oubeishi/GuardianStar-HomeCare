## 8.1 硬件接线图

### 8.1.1 GPIO 紧急按钮接线

```
树莓派 GPIO 引脚图（BCM编码）：

         ┌──────────────────────┐
    3.3V │ 1  ●              ●  2 │ 5V
   GPIO2 │ 3  ●              ●  4 │ 5V
   GPIO3 │ 5  ●              ●  6 │ GND  ◄──┐
   GPIO4 │ 7  ●              ●  8 │ GPIO14   │
     GND │ 9  ●              ● 10 │ GPIO15   │
  GPIO17 │ 11 ● ◄────────────┘    │          │
         │ ...                    │          │
         └──────────────────────┘          │
                                           │
    大红按钮（常开型）                        │
    ┌─────────────┐                        │
    │  ●        ● │                        │
    │  │        │ │                        │
    └──┼────────┼─┘                        │
       │        │                          │
       │        └──────────────────────────┘
       └────────────────────── GPIO17 (BCM)
```

**接线步骤：**
1. 树莓派断电！
2. 按钮一端接 GPIO17（物理引脚11）
3. 按钮另一端接 GND（物理引脚6/9/14/20/25/30/34/39 任选一个）
4. 确认按钮为"自复位"（按下导通，松手断开），非自锁型

### 8.1.2 整体硬件连接

```
┌──────────────┐     HDMI      ┌──────────────┐
│   树莓派 5B   │◄─────────────►│  10寸触控屏   │
│              │    USB触摸     │              │
│  GPIO17 ─────┼───────────────►│  大红按钮     │
│  GND ────────┘                └──────────────┘
│              │
│  3.5mm音频 ──►──► 小音箱
│              │
│  USB-C电源 ──►──► 电源适配器
└──────────────┘
```

## 8.2 系统音频配置

### 8.2.1 强制音频走 3.5mm 口

树莓派默认可能将音频输出到 HDMI，需强制切换到 3.5mm：

```bash
# 方法1：命令行切换
amixer cset numid=3 1   # 1=3.5mm, 2=HDMI

# 方法2：配置文件中永久设置
sudo raspi-config
# 进入 System Options -> Audio -> Force 3.5mm ('headphone') jack
```

### 8.2.2 调整系统音量

```bash
# 设置音量为 85%
amixer set PCM -- 85%

# 保存音量设置
sudo alsactl store
```

### 8.2.3 测试音频

```bash
# 播放测试音（系统自带）
aplay /usr/share/sounds/alsa/Front_Center.wav

# 如果无声，检查：
# 1. 音箱电源是否开启
# 2. 3.5mm插头是否插紧
# 3. amixer 输出是否为 3.5mm
```

## 8.3 软件安装

### 8.3.1 系统依赖

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Python 依赖（树莓派 OS 通常已预装）
sudo apt install -y python3 python3-pip python3-tk

# 安装音频播放库
sudo apt install -y python3-pygame

# 安装 GPIO 库
sudo apt install -y python3-rpi.gpio

# 若使用 pigpio（更稳定的 GPIO 中断）
sudo apt install -y pigpio
sudo systemctl enable pigpiod
sudo systemctl start pigpiod
```

### 8.3.2 创建项目目录

```bash
mkdir -p ~/guardian_star/{sounds,logs}
```

### 8.3.3 复制代码和配置

```bash
# 假设项目克隆到 ~/GuardianStar-HomeCare
cd ~/GuardianStar-HomeCare
cp config.json ~/guardian_star/
cp main.py ~/guardian_star/
cp -r sounds/* ~/guardian_star/sounds/
```

## 8.5 开机自启配置

### 8.5.1 创建自启脚本

创建文件 `/etc/systemd/system/guardianstar.service`：

```ini
[Unit]
Description=GuardianStar HomeCare Service
After=graphical.target

[Service]
Type=simple
User=pi
Environment=DISPLAY=:0
Environment=XAUTHORITY=/home/pi/.Xauthority
WorkingDirectory=/home/pi/guardian_star
ExecStart=/usr/bin/python3 /home/pi/guardian_star/main.py
Restart=always
RestartSec=5

[Install]
WantedBy=graphical.target
```

### 8.5.2 启用服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable guardianstar.service
sudo systemctl start guardianstar.service

# 查看状态
sudo systemctl status guardianstar.service

# 查看日志
journalctl -u guardianstar.service -f
```

### 8.5.3 验证开机自启

1. 重启树莓派：`sudo reboot`
2. 等待系统启动（约 30-45 秒）
3. 观察屏幕是否自动进入 GuardianStar 主界面
4. 若未自动启动，检查日志：`journalctl -u guardianstar.service`

## 8.6 企业微信机器人配置

### 8.6.1 获取 Webhook

1. 下载 **企业微信App**，用手机号注册一个免费企业（选"创建企业"，随便填个公司名，比如"家庭守护"）
2. 在企业微信里创建一个**内部群**，把家人都拉进去
3. 在群设置里点击 **"群机器人"** → **"添加机器人"**
4. 设置机器人名称："奶奶守护星"
5. 复制 Webhook 地址（类似 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx`）

> **重要**：家人**不需要安装企业微信App**，只需要用已有的微信账号，扫描群二维码加入"企业微信外部群"，就能在微信里收到消息通知——和普通微信群聊的体验完全一样。

### 8.6.2 填写到配置

将获取的 `webhook_url` 填入 `config.json` 的 `wecom` 部分。`mentioned_mobile_list` 可选，用于 @ 指定手机号的人。

### 8.6.3 测试通知

```bash
cd ~/GuardianStar-HomeCare
python3 -c "from main import send_wecom; send_wecom('测试消息：GuardianStar 已上线')"
```

## 8.7 触摸屏校准（如触摸偏移）

若触摸位置和实际显示位置不一致：

```bash
# 安装校准工具

```

## 8.8 常见问题排查

| 问题 | 排查步骤 |
| :--- | :--- |
| 屏幕黑屏 | 检查 HDMI 线、屏幕电源、树莓派是否启动（绿灯闪烁） |
| 触摸无反应 | 检查 USB 触摸线、运行 `lsusb` 查看是否识别到触摸设备 |
| 音频无声 | 检查 3.5mm 插头、音箱电源、`amixer` 输出是否为 3.5mm |
| GPIO按钮无反应 | 检查接线（GPIO17+GND）、按钮是否为常开型、用 `gpio readall` 测试 |
| 程序崩溃 | 查看日志 `journalctl -u guardianstar.service -n 50` |
| 启动慢 | 禁用不必要的系统服务：`sudo systemctl disable bluetooth` 等 |
| 企业微信不通知 | 检查网络、Webhook URL 是否正确、Secret 是否过期 |
