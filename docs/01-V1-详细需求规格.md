# 01 - V1 详细需求规格说明书

> **本文档定位**：V1 版本的唯一权威开发依据。涵盖系统架构、界面逻辑、词库定义、反馈机制、紧急子系统、数据运维及非功能性需求。
>
> **适用对象**：开发者（向下执行）、决策者（向上评审）。

---

## 1.1 系统架构总览

| 层级 | 组件 | 说明 |
| :--- | :--- | :--- |
| **物理层** | 树莓派5B主控、10寸触摸屏、3.5mm音箱、GPIO大红按钮 | 全部集成于一体式支架，支持卧床/轮椅场景切换 |
| **系统层** | Raspberry Pi OS + Python 3.11 | 强制音频走3.5mm口，固定WiFi SSID（`NaiNaiHome`） |
| **交互层** | Tkinter 全屏图形界面 | 零文字、纯色块+巨大Emoji（适配文盲及老花眼） |
| **数据层** | 本地JSON配置 + 日志文件系统 | 所有参数外置，操作留痕 |

## 1.3 反馈机制（感官补偿）

| 反馈类型 | 触发条件 | 具体表现 | 持续时间 |
| :--- | :--- | :--- | :--- |
| **视觉闪屏** | 点击任意功能按钮（除"返回首页"外） | 全屏覆盖半透明层，显示超大绿色 ✅ 或红色 🚨 | 0.8秒自动消失 |
| **语音播报** | 点击任意带音频的按钮 | 3.5mm音箱播放对应的 **泰顺蛮讲话 WAV** 文件 | 播放完毕即停（抢断式，立即打断上一个音频） |
| **物理震动（可选）** | 触发红色紧急 | 预留接口，暂不实现 | - |

### 1.3.1 视觉闪屏规格

- 触发后，在当前界面上方叠加一个全屏半透明层（`alpha=0.7`）
- 中央显示超大 Emoji（尺寸≥屏幕高度的40%）
  - 常规按钮：绿色 ✅
  - `pain` 按钮：红色 🚨
- 0.8秒后自动淡出并恢复界面交互
- 闪屏期间，不接受新的点击事件（防止连击误触）

### 1.3.2 语音播报规格

- **播放方式**：抢断式。新点击立即中断当前播放，播放新音频。
- **音频格式**：WAV，16bit/16kHz/单声道（降低文件体积，兼容树莓派音频子系统）
- **音量**：固定 85% 系统音量（在 config.json 中可配置）
- **输出设备**：强制走 3.5mm 音频口（非 HDMI）

## 1.4 物理紧急子系统（最高优先级）

### 1.4.1 触发源

| 属性 | 规格 |
| :--- | :--- |
| 硬件 | GPIO自复位大红按钮（常开型） |
| 接线 | GPIO17（BCM编码） + GND |
| 检测方式 | 硬件中断（下降沿触发） |
| 防抖 | 软件防抖 50ms |

### 1.4.2 系统响应（并行执行，目标 <500ms）

按下按钮后，系统立即执行以下操作：

1. **视觉**：全屏弹无边框红色警报窗，中央显示 🚨 + "紧急求救"（巨大字体）
2. **音频**：循环播放 `emergency.wav` 求救音（最大音量，不可被普通按钮打断）
3. **网络**：发送企业微信群机器人消息给家属群（家属在普通微信中即可接收）
4. **日志**：记录紧急触发时间戳到当日日志

### 1.4.3 解除方式

- 警报窗任意位置点击关闭
- 关闭后返回主菜单
- 紧急音频停止播放

### 1.4.4 紧急音频打断规则

- 普通按钮音频 **不能** 打断紧急音频
- 紧急音频只能由"点击关闭警报窗"或"程序重启"终止

## 1.5 数据与运维

### 1.5.1 操作日志

| 属性 | 规格 |
| :--- | :--- |
| 格式 | 纯文本，每行一条 |
| 内容 | `YYYY-MM-DD HH:MM:SS | button_id | 按钮名称` |
| 示例 | `2026-09-04 14:32:15 | pain | 疼/难受` |
| 存放路径 | `~/guardian_star/logs/YYYY-MM-DD.txt` |
| 轮转策略 | 按自然日分文件，不自动删除 |

### 1.5.2 配置文件

| 属性 | 规格 |
| :--- | :--- |
| 格式 | JSON |
| 存放路径 | `~/guardian_star/config.json` |
| 包含项 | 分辨率、GPIO引脚、企业微信机器人Token、颜色映射、音量、WiFi SSID |
| 热加载 | V1 不支持，修改后需重启程序 |

### 1.5.3 音频资源

| 属性 | 规格 |
| :--- | :--- |
| 数量 | 13个 WAV 文件（12个表达 + 1个紧急） |
| 格式 | WAV，16bit/16kHz/单声道 |
| 命名 | 见 1.2.3 词库表 |
| 存放路径 | `~/guardian_star/sounds/*.wav` |

## 1.6 非功能性需求（V1 验收标准）

| 指标 | 要求 | 验收标准 |
| :--- | :--- | :--- |
| **启动时间** | 从通电到显示主界面 | ≤ 45秒（含系统启动） |
| **触屏响应** | 点击到闪屏/出声 | ≤ 200ms |
| **紧急响应** | 按下按钮到警报触发 | ≤ 500ms |
| **系统稳定性** | 连续运行7天 | 不崩溃、不卡死、音频无杂音 |
| **可搬运性** | 拔插电源即搬走 | 三兄弟家路由器SSID/密码统一，无需重新配网 |

## 1.7 V1 局限性说明（必须向评审人坦白）

- **无AI能力**：不包含跌倒检测、人脸识别、语音识别（依赖华为手环做基础生命告警）。
- **单向沟通**：只能帮奶奶"说出"话，不能理解她说出的模糊声音（仍依赖人工响应）。
- **词库固定**：12个短语在一段时间内是固定的，如需修改需手动替换音频文件并重启程序。
- **无远程管理**：不能通过手机远程查看状态或修改配置，必须现场操作。
