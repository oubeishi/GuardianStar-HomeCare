# 04 - V4 终极养老生态

> **本文档定位**：长期愿景，非近期实施计划。
>
> **核心目标**：当奶奶的右手也无力抬举时，系统仍能工作；当系统需要扩展到其他老人时，能零门槛部署。

---

## 4.1 版本概述

| 项目 | 内容 |
| :--- | :--- |
| **前置条件** | V3 已全面稳定，家庭反馈积极，有意愿持续投入 |
| **预计工期** | 未定（长期迭代） |
| **预估成本** | ~200元（3D打印+普通话音频录制） |
| **核心主题** | 终极关怀：非接触交互 + 双语播报 + 自适应配网 + 有声相册 |

---

## 4.2 功能模块

### 4.2.1 非接触式交互

| 属性 | 规格 |
| :--- | :--- |
| **场景假设** | 奶奶右手也无力抬举，无法触屏 |
| **方案** | 手腕倾斜开关（Wearable Tilt Switch） |
| **硬件** | 3D打印腕带 + 滚珠倾斜传感器（或水银开关） |
| **交互映射** | 手腕左倾 = 确认/下一个；手腕右倾 = 紧急 |
| **使用方式** | 奶奶戴在手上，轻微转动手腕即可触发 |
| **防误触** | 需保持倾斜 ≥ 1秒才生效；紧急需连续右倾2次 |

**腕带设计示意：**

```
┌─────────────────────────────┐
│       [3D打印腕带]           │
│                             │
│    [滚珠开关] ← 左倾触发     │
│    [滚珠开关] → 右倾触发     │
│                             │
│      无线连接主设备           │
└─────────────────────────────┘
```

> **无线方案**：蓝牙低功耗（BLE）或 433MHz 无线模块，避免手腕到主机的线缆束缚。

### 4.2.2 双语播报

| 属性 | 规格 |
| :--- | :--- |
| **场景** | 聘请外地护工，听不懂泰顺话 |
| **方案** | 每个按钮录制两套音频：泰顺话 + 普通话 |
| **播放顺序** | 先播泰顺话（给奶奶听），间隔 1秒，再播普通话（给护工听） |
| **音频文件** | `son.wav` + `son_mandarin.wav`，命名规则后缀区分 |
| **配置项** | `config.json` 中 `bilingual: true/false` |
| **成本** | 需额外录制 12 句普通话音频（可请普通话标准的家属录制） |

### 4.2.3 自适应WiFi配网

| 属性 | 规格 |
| :--- | :--- |
| **场景** | 三兄弟家路由器更换/密码变更，或搬到新环境 |
| **方案** | 设备检测到无法连接预设 WiFi 时，自动开启热点模式 |
| **热点名称** | `GuardianStar-Setup` |
| **配网方式** | 家属用手机连接热点 → 扫码或访问 192.168.4.1 → 输入新 WiFi 密码 |
| **技术实现** | Python 调用 `hostapd` + `dnsmasq`，配网后自动重启网络服务 |
| **安全** | 热点密码印在设备底部标签，首次连接后建议修改 |

**配网流程：**

```
1. 设备通电，检测到 WiFi 连接失败
2. 自动开启热点：GuardianStar-Setup / 密码：NaiNai2026
3. 家属手机连接热点，扫码或访问 192.168.4.1
4. 网页显示附近 WiFi 列表，选择并输入密码
5. 设备保存配置，重启，连接新 WiFi
6. 屏幕显示 "✅ 网络已连接"
```

### 4.2.4 回忆有声相册

| 属性 | 规格 |
| :--- | :--- |
| **功能描述** | 汇总奶奶点击频次最高的短语和对应录音，生成纪念视频 |
| **触发条件** | 手动生成（如春节、奶奶生日） |
| **内容来源** | 日志中统计点击频次 TOP5 的按钮，提取对应音频 |
| **视频模板** | 老照片轮播 + 按钮点击次数字幕 + 方言音频原声 |
| **技术实现** | Python + moviepy 合成视频 |
| **输出格式** | MP4，720p，适合微信分享 |
| **精神价值** | 留存家族记忆，让后代听到奶奶的声音 |

**视频片段示意：**

```
[画面：奶奶的老照片]
[字幕："想儿子" —— 点了 1,247 次]
[音频：son.wav 原声]

[画面：全家福]
[字幕："喝水" —— 点了 892 次]
[音频：water.wav 原声]

...（共5个片段）

[片尾]
"奶奶的守护星，守护了 365 个日夜"
```

## 4.3 V4 非功能性需求

| 指标 | 要求 | 验收标准 |
| :--- | :--- | :--- |
| 手腕倾斜识别 | 动作→触发 | ≤ 500ms |
| 双语播报总时长 | 泰顺话+普通话+间隔 | ≤ 6秒 |
| 配网成功率 | 家属首次操作 | ≥ 90% |
| 视频生成 | 点击生成→输出MP4 | ≤ 10分钟 |

---

## 4.4 开放性设计

V4 阶段，系统应已具备向其他老人家庭复制的条件：

| 复制要素 | 状态 |
| :--- | :--- |
| 硬件标准化 | 树莓派+触控屏+音箱，通用易购 |
| 软件可配置 | config.json 决定词库、颜色、音频路径 |
| 方言可替换 | 替换 `sounds/` 目录即可换方言 |
| 配网零门槛 | 自适应 WiFi 配网，无需技术人员 |
| 成本可控 | 整机成本 < 500元 |

> **愿景**：GuardianStar 不仅守护奶奶，也能守护更多有表达障碍的老年长者。
