# 02 - V2 安全守护升级

> **本文档定位**：V1 稳定运行1个月后的下一阶段规划。
>
> **核心目标**：从"被动表达"升级到"主动预防"，解决夜间坠床和沉默性缺氧两大致死风险。

---

## 2.1 版本概述

| 项目 | 内容 |
| :--- | :--- |
| **前置条件** | V1 已稳定运行 ≥ 1个月，无崩溃、无严重误触 |
| **预计工期** | 约2天（硬件调试+软件联调） |
| **预估成本** | ~50元（传感器） |
| **核心主题** | 安全守护：防坠床 + 生命体征 + 交接班日报 |

---

## 2.2 功能模块

### 2.2.1 防坠床预判

| 属性 | 规格 |
| :--- | :--- |
| **功能描述** | 在床垫下铺压力传感器阵列，检测到重心向床沿转移时，自动语音提醒"别动，等孩子来" |
| **硬件新增** | FSR压力传感器（4个，床垫四角） + ADS1115模数转换器（I2C接口） |
| **触发逻辑** | 床头侧压力骤降 + 床尾侧压力微升 → 判断身体正向床沿移动 |
| **响应动作** | ① 播放 `stay.wav`（"别动，等孩子来"）；② 闪屏显示红色 🛑；③ 记录日志 |
| **灵敏度** | 可配置阈值（config.json），默认灵敏度：中等 |
| **夜间模式** | 22:00-06:00 自动启用，白天关闭（避免轮椅场景误报） |

**硬件接线示意：**

```
床垫俯视图：
┌──────────────────────┐
│  [FSR1]        [FSR2] │  ← 床头侧（靠近枕头）
│                       │
│                       │
│  [FSR3]        [FSR4] │  ← 床尾侧
└──────────────────────┘

FSR → ADS1115 (A0-A3) → 树莓派 I2C (GPIO2/SDA, GPIO3/SCL)
```

### 2.2.2 生命体征接入

| 属性 | 规格 |
| :--- | :--- |
| **功能描述** | 树莓派通过低功耗蓝牙（BLE）定时读取华为手环10的血氧/心率数据 |
| **硬件新增** | 无（树莓派5B自带蓝牙） |
| **读取频率** | 每5分钟一次 |
| **异常阈值** | 血氧 < 92% 或 心率 < 50 或 > 120 |
| **响应动作** | 自动触发紧急语音播报（播放 `emergency.wav`，不等奶奶按键） |
| **通知方式** | 企业微信群机器人消息 + 日志记录 |
| **免责声明** | 本功能为辅助提醒，不构成医疗诊断依据 |

**技术难点：**
- 华为手环10 的 BLE 协议需要抓包或参考开源项目逆向
- 若华为加密协议无法破解，降级方案：改用通用血氧仪（如乐普PC-60FW）

### 2.2.3 交接班日报

| 属性 | 规格 |
| :--- | :--- |
| **功能描述** | 每天早6:00，自动向家族企业微信群推送"昨日简报" |
| **推送内容** | 喝水X次、翻身X次、疼痛X次（附时间点）；手环血氧/心率均值 |
| **格式** | 企业微信群机器人 Markdown 消息 |
| **触发方式** | 树莓派本地定时任务（cron），不依赖外部服务 |
| **示例消息** | 见下方 |

**示例日报：**

```markdown
## 📋 奶奶昨日简报（2026-09-03）

**🙋 需求呼叫：**
- 喝水：3次（08:15, 11:30, 16:45）
- 翻身：2次（10:00, 14:20）
- 疼痛：1次（凌晨02:10）⚠️

**💓 体征概况：**
- 血氧均值：96%（最低93%）
- 心率均值：72次/分（范围65-85）

**🚨 异常事件：**
- 02:10 疼痛按钮触发
- 02:12 紧急按钮触发（已处理）

---
*本简报由 GuardianStar 自动生成*
```

### 2.2.4 音频热更新

| 属性 | 规格 |
| :--- | :--- |
| **功能描述** | 可在不重启程序的情况下，替换方言音频文件 |
| **更新方式** | ① U盘自动检测；② 网络下载（HTTP） |
| **U盘检测** | 插入U盘后自动扫描 `sounds/` 目录，同名文件自动替换 |
| **安全校验** | 仅替换 `.wav` 文件，文件大小限制 ≤ 5MB |
| **生效方式** | 替换后下一个点击立即生效，无需重启 |
| **日志记录** | 记录替换时间、文件名、来源（U盘/网络） |

## 2.3 V2 数据层变更

| 变更项 | V1 | V2 |
| :--- | :--- | :--- |
| 日志字段 | 时间戳 + 按钮ID | 增加：传感器原始值、手环数据 |
| 日志文件 | `YYYY-MM-DD.txt` | 增加：`YYYY-MM-DD-vitals.txt`（体征数据） |
| 配置项 | 基础配置 | 增加：BLE设备MAC、压力阈值、日报开关 |

---

## 2.4 V2 非功能性需求

| 指标 | 要求 | 验收标准 |
| :--- | :--- | :--- |
| 压力检测延迟 | 重心移动→语音提醒 | ≤ 2秒 |
| BLE读取成功率 | 每5分钟一次 | ≥ 90%（允许偶尔蓝牙失联） |
| 日报推送成功率 | 每天一次 | ≥ 99%（本地定时，不依赖云端） |
| 音频热更新 | 替换→生效 | ≤ 3秒 |

---

## 2.5 V2 → V3 的衔接条件

V2 可进入 V3 的前提：
1. 防坠床误报率 < 5%（连续7天统计）
2. BLE手环数据读取稳定（成功率≥90%）
3. 家属日报反馈积极，无信息过载抱怨
