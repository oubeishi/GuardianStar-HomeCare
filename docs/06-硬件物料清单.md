**接线示意：**

```
床垫俯视图：
┌──────────────────────┐
│  [FSR1]        [FSR2] │  ← 床头侧（A0, A1）
│                       │
│                       │
│  [FSR3]        [FSR4] │  ← 床尾侧（A2, A3）
└──────────────────────┘

FSR → ADS1115 (A0-A3) → 树莓派 I2C (GPIO2/SDA, GPIO3/SCL)
ADS1115 VCC → 3.3V
ADS1115 GND → GND
```

## 采购优先级建议

| 优先级 | 物品 | 理由 |
| :--- | :--- | :--- |
| P0（本周） | 音箱、紧急按钮 | V1 最低可运行配置 |
| P1（本周） | 卧床支架 | 影响使用体验，但可用临时支架替代 |

| P3（V2稳定后） | 从音箱、DHT22 | V3 前置条件 |
| P4（长期） | 3D打印腕带 | V4 前置条件 |
