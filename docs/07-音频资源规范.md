# 07 - 音频资源规范

> **本文档定位**：V1 所需的 13 个方言音频文件的录制标准、命名规范、音色要求。
>
> **核心原则**：奶奶听到的是"家人的声音"，而不是冰冷的机器音。

## 7.2 录制标准

### 7.2.1 录音人选择

| 优先级 | 人选 | 理由 |
| :--- | :--- | :--- |
| **首选** | 奶奶最亲近的女儿/儿子 | 音色熟悉，情感真实 |
| **次选** | 泰顺本地亲戚（女性，年龄相仿） | 方言地道，音色温和 |
| **末选** | 聘请本地配音 | 成本高，情感可能不够 |

### 7.2.2 录音环境

- **地点**：安静的房间，关闭风扇/空调，拉上窗帘减少回声
- **设备**：手机即可（iPhone或安卓旗舰机），无需专业麦克风
- **距离**：嘴部距离手机麦克风 15-20cm
- **姿势**：坐姿，放松，自然说话

### 7.2.3 录音参数

| 参数 | 要求 |
| :--- | :--- |
| 采样率 | 16000 Hz（16kHz） |
| 位深度 | 16 bit |
| 声道 | 单声道（Mono） |
| 格式 | WAV（无损） |
| 音量 | 平均 -12dB ~ -6dB，避免削峰 |
| 时长 | 每句 1-3 秒，留 0.3秒 前后空白 |

### 7.2.4 后期处理

1. **降噪**：用 Audacity 的 "Noise Reduction" 功能，采样噪声后应用
2. **标准化**：音量统一至 -6dB
3. **裁剪**：去除前后空白，保留 0.2秒 静音头尾
4. **导出**：File → Export → Export as WAV，选择 16bit PCM

## 7.3 命名规范

```
sounds/
├── son.wav           # 想儿子
├── daughter.wav      # 想女儿
├── time.wav          # 几点了
├── eat.wav           # 吃饭
├── situp.wav         # 坐起来
├── call.wav          # 打电话
├── water.wav         # 喝水
├── turn.wav          # 翻身
├── toilet.wav        # 小便
├── pain.wav          # 疼/难受
├── hotcold.wav       # 热/冷
├── emergency.wav     # 紧急求救
└── stay.wav          # 别动（V2预留）
```

> **严禁**：文件名使用中文、空格、特殊字符。必须为纯英文小写+下划线。

## 7.4 音色与情感要求

| 音频类型 | 音色要求 | 情感基调 |
| :--- | :--- | :--- |
| 唠家常类（son, daughter...） | 温暖、亲切、像家人聊天 | 平和、略带期待 |
| 日常需求类（water, turn...） | 清晰、平和 | 自然、不急躁 |
| 疼痛类（pain） | 略带虚弱感，但清晰可辨 | 求助、不适 |
| 紧急类（emergency） | 洪亮、急促、穿透力强 | 紧急、必须立即响应 |
| 防坠床类（stay） | 温和但坚定 | 安抚、劝阻 |

## 7.5 验收流程

每句音频录制后，必须经过以下验收：

1. **技术验收**：用 Audacity 打开，确认格式为 16bit/16kHz/单声道/WAV
2. **音量验收**：播放时，树莓派连接音箱，音量调至 85%，确保 3米外可清晰听见
3. **用户验收**：**必须让奶奶本人试听**。她听懂、觉得像家人说话，才算通过。
4. **家人验收**：三兄弟中至少两人试听，确认"如果听到这个声音，会立即知道该怎么做"

## 7.6 备份策略

| 备份位置 | 方式 | 频率 |
| :--- | :--- | :--- |
| 本地 | `~/guardian_star/sounds/` 目录 | 实时 |
| Git仓库 | `sounds/` 目录（可用Git LFS） | 每次更新 |
| 云盘 | 百度网盘/阿里云盘家庭共享 | 每月一次 |
| U盘 | 离线备份 | 每季度一次 |

> **重要**：音频是项目的核心资产，一旦丢失需重新录制（尤其是录音人不在身边时）。务必多备份。

## 7.7 V3 双语扩展（预留）

若 V3 启用双语播报，需额外录制普通话版本：

```
sounds/
├── son_mandarin.wav
├── daughter_mandarin.wav
├── ...
└── hotcold_mandarin.wav
```

普通话录音标准同上，但可由普通话标准的年轻人录制。
