# 奶奶的守护星 (GuardianStar-HomeCare)

> **项目定位**：为左侧偏瘫（软瘫期）、文盲、老花眼的泰顺蛮讲话老年女性，打造一套"零文字、纯图形、方言语音"的交互系统，解决卧床老人"表达缺失"与"求救无门"的核心生存需求。

## 快速开始（V1 部署摘要）

```bash
# 1. 克隆仓库
git clone git@github.com:oubeishi/GuardianStar-HomeCare.git
cd GuardianStar-HomeCare

# 2. 准备目录结构
mkdir -p ~/guardian_star/{sounds,logs}

# 3. 复制配置文件
cp config.json ~/guardian_star/

# 4. 复制音频文件
cp sounds/*.wav ~/guardian_star/sounds/

# 5. 配置开机自启
sudo cp autostart.sh /etc/init.d/guardianstar
sudo chmod +x /etc/init.d/guardianstar
sudo update-rc.d guardianstar defaults

# 6. 运行主程序
python3 main.py
```

> 详细部署步骤请参阅 [docs/08-实施手册.md](docs/08-实施手册.md)。

## 版本演进路线图

| 版本 | 主题 | 核心能力 | 预估周期 |
| :--- | :--- | :--- | :--- |
| **V1** | 表达与求救 | 12个固定表达词 + 物理紧急按钮 + 企业微信机器人通知 | 1周内 |
| **V2** | 安全守护 | 压力防坠床 + 手环生命体征 + 日报推送 | V1稳定后1个月 |
| **V3** | 智能互联 | 环境感知 + 全屋广播 + 视频通话 + 健康周报 | V2稳定后2个月 |
| **V4** | 终极生态 | 非接触交互 + 双语播报 + 自适应配网 + 有声相册 | 长期愿景 |

> 各版本详细规格请参阅 `/docs/01-04`。

## 核心指标（V1 验收）

| 指标 | 要求 |
| :--- | :--- |
| 启动时间（通电→主界面） | ≤ 45秒 |
| 触屏响应（点击→闪屏/出声） | ≤ 200ms |
| 紧急响应（按钮→警报） | ≤ 500ms |
| 系统稳定性 | 连续运行7天不崩溃 |
| 可搬运性 | 三兄弟家统一 SSID/密码，插电即用 |
