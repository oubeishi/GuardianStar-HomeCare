# 音频资源目录

本目录存放 GuardianStar 系统所需的泰顺蛮讲话音频文件。

## 文件清单（V1 需准备）

| 文件名 | 对应按钮 | 说明 |
| :--- | :--- | :--- |
| `son.wav` | 想儿子 | 唠家常 |
| `daughter.wav` | 想女儿 | 唠家常 |
| `time.wav` | 几点了 | 唠家常 |
| `eat.wav` | 吃饭 | 唠家常 |
| `situp.wav` | 坐起来 | 唠家常 |
| `call.wav` | 打电话 | 唠家常 |
| `water.wav` | 喝水 | 需要帮忙 |
| `turn.wav` | 翻身 | 需要帮忙 |
| `toilet.wav` | 小便 | 需要帮忙 |
| `pain.wav` | 疼/难受 | 需要帮忙（紧急） |
| `hotcold.wav` | 热/冷 | 需要帮忙 |
| `emergency.wav` | 紧急求救 | GPIO物理按钮 |

## 格式要求

- 格式: WAV
- 采样率: 16000 Hz
- 位深度: 16 bit
- 声道: 单声道 (Mono)
- 音量: 标准化至 -6dB
